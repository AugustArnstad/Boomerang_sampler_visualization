This repo contains visualizations for the PDMP Boomerang sampler. 
It visualizes the sticky boomerang algorithm, with its events and trajectories, and the piecewise linear interpolation method to perform Poisson thinning.

Sticky Boomerang algorithm:
https://augustarnstad.github.io/Boomerang_sampler_visualization/boomerang_trajectories.html

Piecewise linear interpolation:
https://augustarnstad.github.io/Boomerang_sampler_visualization/piecewise_thinning.html
